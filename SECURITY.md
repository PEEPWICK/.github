# Security policy

## Reporting a vulnerability

Please report security issues **privately**. Don't open a public issue.

1. Go to the affected repository's **Security** tab.
2. Choose **Report a vulnerability** and describe what you found, how to reproduce it and which
   version you used.

We read every report, confirm what we can reproduce and tell you what we will do about it. When a
fix ships, we credit you in the release notes unless you'd rather stay anonymous.

## Supported versions

Only the newest version of each project receives security fixes. PEEPWICK Browser updates itself,
so most users get fixes without doing anything.
